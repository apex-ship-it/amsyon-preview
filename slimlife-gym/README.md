# Slim Life Gym — Nellore concept

This folder contains an AMSYON concept preview for a Slim Life Gym public website and a gym-management portal.

## Pages
- `index.html` — public website concept with training overview, Nellore location cards and contact path.
- `portal.html` — sample admin dashboard and management screens.

## Portal modules shown
Overview, members, attendance, plans and renewals, collections, expenses, employees, payroll, equipment maintenance, reports, and user access settings. The demo includes sample navigation, search, CSV export, and add-member, record-collection, log-expense and add-employee forms.

## Design system
The shared `styles.css` defines the color palette, typography, spacing, component radii, buttons, badges, cards, tables, responsive breakpoints and portal layout. The direction uses deep forest green, warm off-white and lime accents as a proposed concept; it is not verified as Slim Life's existing brand palette.

## Important
All member names, staff, attendance, prices and financial figures in the portal are fictional demonstration data. Form entries exist only in browser memory and clear on refresh. There is no authentication, database, payment gateway, payroll calculation, tax filing, or live Slim Life integration. Membership details and branch information must be confirmed by Slim Life before launch. The pages are concept previews, not production software or an official Slim Life website.
